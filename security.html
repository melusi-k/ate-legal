Security

Last updated: 11 October 2026

ate is designed to keep user data as private and secure as possible. This document summarises the core security principles behind the app and the hosting setup.

Core practices

  • Passwords and account credentials are handled by a secure authentication provider rather than by app-side custom storage.
  • Data is transmitted using encrypted connections and persisted with provider-level controls.
  • Access to synced user data is restricted to the user's own account.
  • Recipe extraction and AI processing are performed on-device wherever possible.

Responsible disclosure

If you discover a security vulnerability or a risk in the app or site, please contact the developer privately before disclosing it publicly. Include the details of the issue and steps to reproduce it if possible.

Limitations

No system is perfectly secure. The developer makes reasonable efforts to maintain security, but users should also keep their device, app updates, and authentication details secure.
